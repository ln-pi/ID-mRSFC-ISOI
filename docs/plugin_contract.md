# SeedFC 来源契约

`configs/SeedFC_Aseries_noGSR.yaml` 从 `../data/SeedFC_001_008/organized` 读取整理好的采集。源目录下按 branch、series、week、run、mouse 定位 `FC_matrices.npz`。读取 `r` 与 `seed_names`，在写周表前核对各采集的标签、顺序、矩阵和可用的身份字段。输入已包含的 `z` 不会再次变换成原始相关。

每个分区显式列出排除的 seed 名。同一分区需要至少三个保留的 seed。未知排除标签或跨记录标签不一致将终止转换。缺少文件或分区内存在非有限连接的记录保留在审计中，对应周表单元格为空。完整有限矩阵还须对称、相关系数在允许范围内、主对角线为 1。

正式配置保留 22 个 seed，三个分区均使用空排除列表，因此同一记录会在三个分区使用相同连接。分区名称本身不定义解剖归属。2026-11-03 核验的 Aseries/noGSR 配置请求 280 个采集，读到 277 个 22×22 矩阵，3 个缺失。277 个矩阵均缺少 FRP_L、FRP_R，其中 3 个矩阵还有其他 seed 缺失。按正式口径，每个分区均为 0 个完整记录。真实几何验收暂缓；作为工程验收的合成结果单独保存。

`--stage seedfc --dry-run` 只核验源文件。`--start seedfc` 先生成带标签的原生周表、逐记录审计和来源摘要，再进入 edges。启用该来源的配置与原生 preprocess/fc 互斥。
