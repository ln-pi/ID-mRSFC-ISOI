# Optimization

1. **确认当前 trial 的实际含义**
   - 明确 `00w–13w` 是否为不同周次，`Run01/Run02` 是否为每周两次采集。
   - 据此确定研究问题是“增加记录长度”，还是“累积不同时间点的记录”。
   - 若是周次，需要考虑年龄、发育及采集时间的影响，不能直接沿用原论文的连续时间切片解释。

2. **修正相似性向量提取，再重跑 03–05**
   - 将当前 `np.tril_indices(..., k=1)` 改为严格非对角线、不重复的连接提取。
   - 保留固定 8 只 mouse 和三个网络分类。
   - **02 无需重算**，其 FC 矩阵仍可使用。
   - 保存旧结果作对照，避免新旧数值混用。

3. **重新设计 05 的 DD/ND 统计检验**
   - 不再把 14 个相互重叠的累计条件当成独立样本。
   - 以 mouse 为单位设计重采样或置换，并保留重复测量结构。
   - ND 依赖 mouse 排列，建议降低其结论权重，或评估替代指标。
   - 完成前，05 的图可以作描述，现有显著性不宜作为主要证据。

4. **统一显著性与效应量计算口径**
   - Shuffle p 值采用 `(超过或等于真实值的次数 + 1)/(随机化次数 + 1)`，避免输出 `p=0`。
   - 统一 03、04 的配对效应量定义，解决标准差 `ddof` 不一致。
   - 提前明确多重比较范围：最终条件为主要检验，还是全部累计条件均参与推断。
   - 优先报告效应量及不确定性，而非只看是否显著。

5. **检验 trial 累积顺序和样本选择的稳健性**
   - 当前只使用“前 N 个 trial”，结果可能受具体顺序影响。
   - 若科学问题允许，可重复抽取 N 个 trial，观察识别率和 relEffect 的分布。
   - 若 trial 是周次，应区分时间顺序分析与随机子集分析。
   - 以固定 8 只作为主分析；可将“排除 13w、保留 9 只”作为独立敏感性分析，避免替换主分析后挑选更好看的结果。

6. **重新量化 Edge 结论**
   - 除前 1% 外，检查前 2%、5% 等阈值下结果是否稳定。
   - 比较跨半球、模块内和感觉系统连接时，考虑各类候选边数量不同。
   - 区分“数量较多”与“相对于基线显著富集”。
   - 若跨半球优势随 trial 改变，应如实表述为条件依赖的结果。
