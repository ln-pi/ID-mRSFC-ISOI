### 当前支持的描述

- 两组都存在可重复的同日连接结构。扣除同周对照模式后，N 组平均模式相关约 0.50–0.60，A 组约 0.46–0.57；不能简单将原先较低的跨周识别率归因于模型组同日采集普遍不稳定。
- 偏离模式可重复，不等于偏离幅度一致。逐周幅度 ICC 的中位数约 0.17–0.49，不宜凭单 Run 或单周峰值判断疾病严重程度。
- 联合区出现模型组相对 00w 变化量及跨 Run 同向变化成分较大的描述性现象；感觉区和全脑不呈现统一方向。
- N 的对照偏离可能包含模型组共有变化和个体特点；重复性较高不等于个体指纹更强或疾病更重。

### 尚不能据此得出的结论

- 尚未证明模型组病程异质性显著大于对照组，也未证明网络轨迹对应实际症状进展。
- 相对 00w 的距离增大不等于疾病恶化，对照组同样存在时间变化。
- 报告未作正式组间显著性检验。按鼠重采样区间固定了对照模板，未传播模板估计的不确定性；留一法残差之间也存在依赖，不能把这些区间作为完整组间推断。
